# 🎫 Дискорд-бот с тикетами (русский)

Бот системы тикетов с логами, категориями, панелью создания тикетов, кнопками
управления внутри тикета и панелью администрации. Все команды на русском и
работают через префикс `!`.

## Возможности
- Создание тикетов через выпадающее меню категорий.
- Отдельный канал под каждый тикет; видят только автор, поддержка и администрация.
- Внутри тикета кнопки: **Принять тикет**, **Закрыть тикет**, **Закрыть с причиной**.
- Логи тикетов в отдельный канал + текстовый транскрипт при закрытии.
- 4 категории по умолчанию: «Заявка на кастом. роль», «Заявка на раздачу
  промокода», «Заявка на модерацию», «Покупка товара». Можно менять текст, эмодзи и описание.
- Панель администрации: настройки + статистика.
- Роль администрации настраивается командой `!роль_админ`.
- **Модерация:** баны, разбаны, кики, муты (тайм-ауты) и размуты — с логами.
- **Автомод:** авто-мут за спам/флуд и за приглашения в Discord (ссылки `discord.gg`
  и подобные). Обычные ссылки **не** наказываются. Иммунитет у поддержки/администрации,
  у ролей с правом «Управление сообщениями» и у назначенных ролей.
- Красивая интерактивная панель настроек автомода с кнопками-переключателями.
- **🧠 ИИ-собеседник (role play):** упомяните бота (`@бот`) в чате — он ответит
  как ролевой персонаж, который «шарит за мемы» и интернет-культуру. Работает через
  любой OpenAI-совместимый API (OpenAI, Groq, OpenRouter и т.п.). Помнит последние
  реплики в канале, есть антифлуд, вкл/выкл и смена образа персонажа.
- **🌦️ Погода:** команда `!погода <город>` — текущая погода и прогноз на день
  (бесплатный сервис Open-Meteo, **API-ключ не нужен**).
- **🎉 Развлечения и утилиты:** `!мем`, `!аватар`, `!юзер`, `!сервер`, `!кости`,
  `!шар` (магический шар), `!выбери`.

## Токен и конфигурация
Токен читается в таком порядке приоритета:
1. Переменная окружения `DISCORD_TOKEN` (или `TOKEN`) — **рекомендуется для хостинга**.
2. Файл `config.json` (удобно для локального запуска).

Префикс — переменная окружения `PREFIX` или поле `"prefix"` в `config.json` (по умолчанию `!`).

> ⚠️ **Безопасность:** `config.json` и `data.json` добавлены в `.gitignore` и **не**
> должны попадать в репозиторий. Если токен когда-либо оказался в коде или в
> публичном месте — немедленно сбросьте его в Discord Developer Portal (**Bot → Reset Token**).

## 🧠 Настройка ИИ-собеседника
ИИ отвечает на **упоминания** бота. Работает с любым OpenAI-совместимым провайдером —
достаточно задать переменные окружения (или поля в `config.json`):

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `AI_API_KEY` | да (для ИИ) | — | API-ключ провайдера (или `OPENAI_API_KEY`) |
| `AI_BASE_URL` | нет | `https://api.openai.com/v1` | базовый URL API (для Groq/OpenRouter и т.п.) |
| `AI_MODEL` | нет | `gpt-4o-mini` | модель для ответов |
| `AI_BOT_NAME` | нет | `Ботя` | имя персонажа по умолчанию (role play) |

Без `AI_API_KEY` все остальные функции бота (тикеты, модерация, погода, мемы) работают
как обычно — при упоминании бот лишь подскажет, что ИИ не настроен.

Примеры совместимых провайдеров: **OpenAI** (`https://api.openai.com/v1`),
**Groq** (`https://api.groq.com/openai/v1`), **OpenRouter** (`https://openrouter.ai/api/v1`).
На сервере ИИ можно выключить командой `!ии выкл` и сменить образ персонажа `!ии_имя <имя>`.

## Установка (локально)
1. Установите Python 3.9+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. В [Discord Developer Portal](https://discord.com/developers/applications) в разделе
   **Bot** включите два переключателя (Privileged Gateway Intents):
   - **MESSAGE CONTENT INTENT**
   - **SERVER MEMBERS INTENT**
4. Скопируйте `config.example.json` в `config.json` и вставьте токен, **либо**
   задайте переменную окружения `DISCORD_TOKEN`.
5. Пригласите бота на сервер с правами: *Управление каналами*, *Просмотр каналов*,
   *Отправка сообщений*, *Встраивание ссылок*, *Прикрепление файлов*,
   *Управление сообщениями* (для автомода), *Тайм-аут участникам* (муты),
   *Выгонять участников* (кики), *Банить участников* (баны).
   Важно: роль бота должна быть **выше** ролей тех, кого он должен наказывать.
6. Запустите бота:
   ```bash
   python bot.py
   ```

## Хостинг на Railway (бесплатно)
1. Залейте этот репозиторий в GitHub (уже сделано).
2. На [railway.com/new](https://railway.com/new) выберите **Deploy from GitHub repo**
   → выберите репозиторий с ботом.
3. Railway автоматически определит Python, поставит зависимости из
   `requirements.txt` и запустит процесс из `Procfile` (`worker: python bot.py`).
4. В настройках сервиса → **Variables** добавьте переменные:
   - `DISCORD_TOKEN` = ваш токен бота.
   - (необязательно) `PREFIX` = `!`.
   - (для ИИ) `AI_API_KEY` = ключ вашего провайдера; при необходимости `AI_BASE_URL`,
     `AI_MODEL`, `AI_BOT_NAME` (см. раздел «Настройка ИИ-собеседника»).
5. **Чтобы настройки не терялись при передеплое:** добавьте том (**Volume**) и
   смонтируйте его, например, в `/data`. Затем добавьте переменную
   `DATA_DIR=/data` — бот будет хранить `data.json` на этом томе.

> Файловая система Railway эфемерна: без тома `data.json` сбрасывается при каждом
> передеплое, и все настройки серверов пропадут. Переменная `DATA_DIR` решает это.

## Быстрая настройка на сервере Discord
Выполните по порядку (нужны права администратора сервера при первом запуске):

```
!роль_админ @Администрация          — назначить роль администрации
!роль_поддержки @Поддержка          — кто видит тикеты
!категория_тикетов <ID категории>   — категория Discord для каналов тикетов
!канал_логов #логи-тикетов          — куда писать логи
!канал_панели #создать-тикет        — где будет панель создания тикетов
!текст_панели Заголовок | Описание  — (необязательно) текст панели
!панель_тикетов                     — опубликовать панель создания тикетов
!панель_админ                       — открыть панель администрации
```

> ID категории Discord: включите «Режим разработчика» в настройках Discord,
> нажмите правой кнопкой на категорию → «Копировать ID».

## Список команд
| Команда | Описание |
|---|---|
| `!роль_админ <@роль\|ID>` | назначить/убрать роль администрации |
| `!роль_поддержки <@роль\|ID>` | добавить/убрать роль поддержки |
| `!категория_тикетов <ID>` | категория Discord для каналов тикетов |
| `!канал_логов <#канал>` | канал для логов |
| `!канал_панели <#канал>` | канал для панели создания тикетов |
| `!текст_панели Заголовок \| Описание` | изменить текст панели |
| `!панель_тикетов` | опубликовать панель создания тикетов |
| `!панель_админ` | открыть панель администрации |
| `!категории` | изменить категории (текст, эмодзи, описание) |
| `!настройки` | показать настройки |
| `!статистика` | показать статистику |
| `!помощь` | список команд |

### Модерация
| Команда | Описание |
|---|---|
| `!бан @участник [причина]` | забанить (администрация) |
| `!разбан <ID> [причина]` | разбанить (администрация) |
| `!кик @участник [причина]` | кикнуть (администрация) |
| `!мут @участник <время> [причина]` | мут/тайм-аут (поддержка) |
| `!размут @участник [причина]` | снять мут (поддержка) |

Формат времени для мута: `30с`, `10м`, `2ч`, `1д` (латиница тоже: `30s`, `10m`, `2h`, `1d`).
Без единицы — минуты. Максимум по правилам Discord — 28 дней.

### Автомод
| Команда | Описание |
|---|---|
| `!автомод` | панель настроек (вкл/выкл, пороги спама и мутов) |
| `!канал_модлогов <#канал>` | канал логов модерации/автомода (иначе — общий канал логов) |
| `!автомод_иммунитет <@роль>` | выдать/убрать иммунитет роли |

- **Анти-спам:** если участник отправляет N сообщений за T секунд — авто-мут и очистка
  сообщений (пороги настраиваются кнопкой «Настроить пороги»).
- **Анти-приглашения:** сообщение с приглашением в Discord (`discord.gg/...`,
  `discord.com/invite/...`) удаляется, автор получает мут. Обычные ссылки не трогаются.

### ИИ-собеседник (role play)
| Команда | Описание |
|---|---|
| `@упоминание бота` | ответ ИИ-персонажа, который шарит за мемы |
| `!ии [вкл\|выкл]` | вкл/выкл ИИ-собеседника (администрация) |
| `!ии_имя <имя>` | сменить образ персонажа для role play (администрация) |
| `!забудь` | очистить память разговора в текущем канале |

### Погода, развлечения и утилиты
| Команда | Описание |
|---|---|
| `!погода <город>` | текущая погода и прогноз на день (Open-Meteo) |
| `!мем [сабреддит]` | случайный мем |
| `!аватар [@]` | показать аватар участника |
| `!юзер [@]` | информация об участнике |
| `!сервер` | информация о сервере |
| `!кости 2d6` | бросок кубиков |
| `!шар <вопрос>` | магический шар предсказаний |
| `!выбери a \| b \| c` | случайный выбор из вариантов |

## Файлы
- `bot.py` — код бота.
- `config.example.json` — шаблон конфигурации (скопируйте в `config.json`).
- `config.json` — токен и префикс (локально; в `.gitignore`).
- `data.json` — создаётся автоматически, хранит настройки и статистику каждого сервера (в `.gitignore`).
- `requirements.txt` — зависимости.
- `Procfile` — команда запуска для хостинга (Railway и т.п.).

## Примечания
- Настройки хранятся в `data.json` и не теряются при перезапуске; кнопки панелей
  тоже продолжают работать после перезапуска бота.
- Один пользователь не может открыть два тикета одной категории одновременно.
