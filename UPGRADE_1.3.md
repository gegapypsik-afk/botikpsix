# Обновление бота v1.3 - Новые функции

## Что нового

### 1. Улучшенный ИИ-собеседник
- Расширенный системный промпт с более адаптивным поведением
- Улучшенная реакция на настроение собеседника
- Лучшее понимание контекста разговора
- Поддержка более естественных диалогов

### 2. Система уровней с кастомной валютой
Команды:
- `!уровни [@участник]` — показать текущий уровень и XP
- `!топ` — топ 10 участников по уровням
- `!валюта` — настройки валюты на сервере
- `!настройки_уровней` — настройка системы (администрация)

Настройки:
- Настраиваемый эмодзи валюты
- Название валюты и форма множественного числа
- XP за сообщение (по умолчанию 5)
- XP за картинку (по умолчанию 10)
- Кулдаун между начислениями (по умолчанию 60 сек)
- Канал для публикации лидерборда

### 3. Логирование модерации
Новые команды:
- `!список_банов` — список всех забаненных участников
- `!список_мутов` — список участников с активными тайм-аутами
- `!канал_модлогов` — канал для логов модерации/автомода

Панель администрации обновлена с кнопками для просмотра логов.

### 4. Музыкальный плеер
Поддержка Яндекс Музыка и ВК Музыка.

Команды:
- `!в playing` — подключиться к голосовому каналу
- `!выход` — отключиться
- `!играй <название или ссылка>` — воспроизвести музыку
- `!стоп` — остановить
- `!пропустить` — пропустить трек
- `!громкость [1-100]` — установить громкость
- `!цикл` — включить/выключить повтор
- `!очередь` — показать очередь
- `!очистить_очередь` — очистить очередь

### 5. Улучшенная панель администрации
Новые кнопки:
- `Логи модерации` — информация о логах и командах
- `Система уровней` — статистика уровней

### 6. Скрытие бота из Discoverability

**Важно:** Чтобы сделать бота невидимым для добавления через профиль:

1. Перейдите в [Discord Developer Portal](https://discord.com/developers/applications)
2. Выберите ваше приложение
3. В разделе **Installation**:
   - Отключите переключатель **"Add to Server"**
   - Или настройте **Install Parameters**:
     - Scopes: выберите только `bot`
     - Bot Permissions: выберите нужные права

**Как добавлять бота:**
- Используйте прямую ссылку добавления с нужными правами
- Ссылка формируется так:
  ```
  https://discord.com/oauth2/authorize?client_id=ВАШ_ID&permissions=ПРАВА&scope=bot
  ```
- Пример с правами для этого бота:
  ```
  https://discord.com/oauth2/authorize?client_id=123456789&permissions=268823622&scope=bot
  ```

## Установка обновления

1. Обновите зависимости:
```bash
pip install -r requirements.txt --upgrade
```

2. Обновите `config.json` (если используется локальный конфиг):
Добавьте новые поля:
```json
{
  "currency_emoji": "💰",
  "currency_name": "монеты",
  "currency_plural": "монет"
}
```

3. Перезапустите бота:
```bash
python bot.py
```
